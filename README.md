# ALONG 跟课

课堂实时听写、中英字幕、教练三条回复、翻译、AI 对话、笔记和纪要。

点「开始听」上课，暂停不会结课，结课才写成纪要。「再出一份」会另存新纪要，并标明由哪一份再出。

## 本地运行

需要 [xAI API key](https://console.x.ai/)。

```bash
npm install
export XAI_API_KEY=your_key
npm run dev
```

浏览器打开提示的地址。Chrome 下实时听写最稳。

## 数据存在哪

纪要、笔记、主题存在**你这台浏览器的 localStorage**，不进云端。

- 不会因为关掉标签而丢，除非清站点数据、换浏览器、或换设备
- 浏览器一般给每个站点大约 **5 MB**
- 本应用最多保留 **40 堂**纪要，每堂笔记最多 **40 条**

要长期保存：定期导出，或自己接数据库。换电脑不会自动同步。
